OFS Data Rules

Field: FIELD=VALUE
Multi-value: FIELD:1=VALUE
Sub-value: FIELD:1:2=VALUE
Multiple values: repeat the same field with different MV/SV positions.
Comma in content: OFS data can represent a comma using ? in environments following the documented escaping convention.
Transaction options: VERSION / FUNCTION / PROCESSING FLAG, with optional GTS control and authoriser count depending on configuration.
ID information: the fourth segment is operation-specific; for transactions it is normally the record/transaction ID.
Never put real banking credentials into examples, screenshots or shared troubleshooting messages.
